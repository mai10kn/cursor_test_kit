# Input cho v2

Đã có bộ QA Core giả lập giống nhau ở mọi phiên bản. Không thay đổi input khi benchmark. Nếu muốn dùng tài liệu dự án, hãy sao chép sang thư mục này và chỉ định chính xác path cho AI. Không đưa PII/secret nếu chưa được phép.

`requirements.md` + `testcases.csv` là đủ để chạy thử; nhãn đáp án chỉ ở thư mục `evaluation/ground-truth/` cấp trên, không đưa cho Cursor Agent.
